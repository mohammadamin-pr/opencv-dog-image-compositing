# OpenCV Dog Image Compositing

A Python and OpenCV project that extracts dog images from their original backgrounds and combines them with a different background.

## Technologies

- Python
- OpenCV

## Features

- Reading images
- Resizing images
- Converting images to grayscale
- Creating binary masks
- Using thresholding
- Using bitwise image operations
- Extracting objects from images
- Combining images with a different background
- Adding text to images
